What should a DeepSeek-V3 training profile look like?

A simulator you can read: a memory model and a Perfetto-style trace estimator for DSv3-family MoE training, built up one refinement at a time. This page collects the posts and hosts the sandbox; each post works one real configuration end to end.

Sandbox

Every widget, linked to one configuration. The structure widget sets the layer stack; the transformer-block schematic sets each matmul's precision and each op's save 💾 / recompute ↻ mark; the controls set hardware, parallelism, and schedule, and every simulated effect toggles independently. All of it drives the memory watermark and the simulated profile at once. State persists in the URL, so a configuration is shareable.

Things to try: start from a non-PP config and walk it toward PP16; push seqLen or the global batch until a bar goes red; H800 with only expert a2a on; granularity: op zoomed into a single MoE layer; dpRanksToSim: 4 with jitter on; flip the structure widget between all-MoE and 3-dense-first and watch rank 0.
