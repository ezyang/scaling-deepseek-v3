scratch: squares-for-linear, bars-for-log

Prototypes for the proposed global visual language: SQUARES (countable units) for linear charts, BARS for log charts, spans for time intervals. Memory units are tall-thin rects; FLOP units are squares. Not part of the series.

1 · fold map in blocks (memory = tall-thin units, 448 MiB each)

Fixed unit, so the EP knob changes the COUNT (try EP1 — the honest explosion). Layer separations widened; the last unit of each layer is a partial-width sliver so drawn area stays exact.

2 · per-rank compute: eight rectangles of FLOP squares

Same fold, area = forward FLOPs per token instead of width = resident params. One tile per slot (emb is a dashed stub — a lookup, no FLOPs; the head is dashed but LARGE). Compute is EP-independent (activated experts, not resident ones) — no knob.

3 · full sim without parameter squares (nostrips)

The PP1/EP1 answer: stop drawing the in-box parameter squares entirely — when nothing fits, the message is "this is big" and the log chart carries it. Amber activation chips stay. Compare with the live 02 sim.
